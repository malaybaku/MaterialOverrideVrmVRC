# Material Override VRM for VRChat の使い方

VRChat向けにセットアップしたアバターから、VMagicMirrorで使用する `.mouv` ファイルを作成するためのパッケージです。アバターをVRMに変換し、元の見た目に使われているマテリアルを組み合わせて出力します。

**まずは「まとめてエクスポート」を使ってください。** 「まとめてエクスポート」が利用できない場合や、保存したマテリアルを調整してから出力したい場合は「ステップごとにエクスポート」を使います。

## .mouvに入るアバターの情報

`.mouv` は、基本的にはNDMF VRM ExporterでVRMに変換したアバターの情報を使います。

ただし、見た目に使うマテリアルは、VRM用のMToonに変換される前のものを保存し、テクスチャとともに `.mouv` に埋め込みます。アバターの加工ツールによって出力時に作られたマテリアルも、この段階でアバターに設定されていれば対象になります。

保存するのは出力直前にモデルへ設定されているマテリアルです。アニメーションや衣装切り替えでのみ使うマテリアルを、すべて収集するものではありません。

## はじめに

Unity 2022.3のVRChatアバタープロジェクトで使用します。本パッケージの導入先は[READMEの案内](README.md#導入と使い方)を参照してください。

導入後、次の準備をしてください。

1. Unityの **Tools > Material Override VRM > For VRChat: Setup** を開きます。
2. セットアップ画面に操作が必要な項目があれば、画面の案内に従って必要なパッケージを導入します。
3. 「セットアップ完了」と表示されたら、**エクスポート画面を開く** を押します。

エクスポート画面は **Tools > Material Override VRM > For VRChat: Export Avatar** からも開けます。LanguageでJapaneseを選ぶと、本パッケージの案内を日本語で表示できます。

UniVRMは、セットアップ画面にある2つのURLを **Window > Package Manager > + > Add package from git URL...** からそれぞれ追加します。案内するバージョンは0.131.4です。取得にはGitとインターネット接続が必要です。既に対応版が導入済みなら追加は不要です。従来のAssets配下へ導入したUniVRMがある場合は、重複して導入せず、先に導入方式を整理してください。

NDMF / NDMF VRM Exporterが不足している場合はVCC / ALCOMから導入します。NDMF VRM Exporterの導入方法は、セットアップ画面のリンク、または[同パッケージの説明](https://github.com/hkrn/ndmf-vrm-exporter)を参照してください。導入・コンパイル完了後に **パッケージを再確認** を押します。

元アバターには、シーン上に配置した、VRC Avatar Descriptorが付いているオブジェクトを指定します。

**VRMへの変換設定や、作者・ライセンスなどの設定については、[NDMF VRM Exporterの説明](https://github.com/hkrn/ndmf-vrm-exporter)を参照してください。** 本パッケージでも、VRMファイルを出力する部分にはNDMF VRM Exporterを使用します。先に元アバターのVRM出力設定を済ませてください。

元アバターには **VRM Export Description** を追加し、作者・ライセンスなどを設定してください。「まとめてエクスポート」では、このコンポーネントがない場合、警告を表示してエクスポートボタンを無効にします。

VRM Export Descriptionの **MToon Options** を変更しても、最終的な `.mouv` での見え方には影響しません。`.mouv` の表示には、MToonへの変換前に保存したマテリアルを使うためです。出力した `.vrm` を単独で使用する場合には、MToon Optionsの設定が反映されます。

### マテリアルの対応

`.mouv` の表示にはURPに対応したシェーダーが必要です。lilToonを使っている場合は、出力時のRender Pipeline切り替えに合わせてシェーダーを再生成します。StandardなどのマテリアルをURP/Litへ自動変換する機能は、本パッケージには含まれません。必要に応じて、保存したマテリアルを退避してから調整してください。

## おすすめ：まとめてエクスポート

1. 「エクスポート方法」で **まとめてエクスポート** を選びます。
2. 「元アバター」に、出力したいアバターを指定します。
3. **エクスポート** を押し、`.mouv` の保存先を選びます。プロジェクトに出力ファイルを増やしたくない場合は、`Assets` の外のフォルダを選んでください。
4. 完了するまで待ち、出力した `.mouv` をVMagicMirrorで読み込みます。

VRMは、`.mouv` の保存先の拡張子を `.vrm` に変更したファイルとして保存します。同名ファイルがある場合は、出力開始前に確認が表示されます。「OK」で既存のVRMを上書きして続行し、「キャンセル」でエクスポートを中止します。出力成功後、今回の処理用にプロジェクトへインポートしたVRMは削除されます。出力に失敗した場合は、確認・再試行のために処理用VRMがプロジェクトに残ることがあります。

通常は「詳細設定」を変更する必要はありません。マテリアル情報は出力のために一時的に作成され、出力が終わると削除されます。手編集や再利用のために残したい場合は、出力前に「詳細設定」の **エクスポートしたマテリアル情報をプロジェクトにも残す** をオンにしてください。

「まとめてエクスポート」を使用できない旨が表示された場合は、エクスポート方法を **ステップごとにエクスポート** に変更してください。

## 必要な場合：ステップごとにエクスポート

「まとめてエクスポート」が利用できない場合のほか、マテリアルを調整したい場合や、保存済みのVRMとマテリアル情報を使って再出力したい場合に使います。

### Step1：VRM (.vrm) を出力

1. 「エクスポート方法」で **ステップごとにエクスポート** を選びます。
2. 「元アバター」に、出力したいアバターを指定します。
3. **マテリアル保存を有効にする** を押し、「マテリアルの保存」が **セットアップ済み** になっていることを確認します。既にセットアップ済みの場合は、そのままで構いません。
4. NDMF VRM Exporterの **Export** ボタンからVRMを出力します。次のStep2で指定できるよう、**プロジェクトの `Assets` 以下のフォルダにVRMをエクスポートしてください。**

VRM出力時には、マテリアルとテクスチャも「マテリアル情報（Snapshot）」として保存されます。同名アバターの前回分は上書きされるため、残したいデータがある場合は、[保管・手編集するときの注意](#マテリアル情報を保管手編集するときの注意)を確認してから出力してください。

VRM出力側の設定やエラーについては、[NDMF VRM Exporterの説明](https://github.com/hkrn/ndmf-vrm-exporter)を参照してください。

### Step2：Material Override VRM (.mouv) を出力

1. 「出力済みVRM」に、Step1で出力した `.vrm` アセットをProjectウィンドウから指定します。シーンへ配置したモデルは指定できません。
2. 「マテリアルの指定方法」は、通常 **自動で選択 (VRMのアバター名と一致する最新)** のままで構いません。
3. 「自動選択マテリアル」のアバター名と作成時刻を確認します。
4. **エクスポート** を押し、`.mouv` の保存先を選びます。

古いVRMを使う場合や、保管・手編集したマテリアルを使う場合は **手動で選択** に切り替え、「手動選択マテリアル」に対象フォルダの `Snapshot.asset` を指定します。自動で選択できない場合も、手動で指定できます。

**VRMとマテリアル情報は、同じ出力時に作成した組み合わせを使ってください。** 自動選択はアバター名と作成時刻をもとにするため、同名アバターが複数ある場合や、その後に再出力した場合には、意図した組み合わせになっているか確認してください。

すでにVRMとマテリアル情報が揃っていれば、Step1をやり直す必要はありません。

出力に使うVRMは処理中だけシーンに配置し、成功・失敗にかかわらず終了時に削除します。保存先選択をキャンセルした場合は配置しません。Project内の `.vrm` アセットは残ります。

## マテリアル情報を保管・手編集するときの注意

「ステップごとにエクスポート」、または「まとめてエクスポート」でマテリアル情報を残す設定をオンにした場合、マテリアル情報は次の場所に保存されます。

```text
Assets/MaterialOverrideVrm/Generated/MaterialSnapshots/<アバター名>_<識別子>/
```

フォルダ内には `Snapshot.asset` と、その出力に使うマテリアル・テクスチャが入っています。保存が完了すると、UnityのConsoleにも保存先フォルダを表示します。

**Generated以下は再生成するための保存場所です。同じ名前のアバターを再出力すると、確認ダイアログなしで前回分を上書きします。** 別のシーンにあるアバターでも、名前が同じなら対象になります。

次のような場合は、次回の出力や編集の前に退避してください。

- 前回の見た目を残し、あとから同じ状態で再出力したい場合。
- 複数の衣装・設定で出力した結果を保管したい場合。
- URP対応などのために、保存されたマテリアルを手編集したい場合。

### 退避の手順

1. UnityのProjectウィンドウで、残したい `Snapshot.asset` が入ったアバター名のフォルダを探します。
2. **そのフォルダ全体を、Generatedの外へ移動します。** 例えば `Assets/MaterialOverrideVrm/SavedSnapshots/` を作り、その中へ移動します。複数残す場合は、フォルダ名に用途や日付を付けると区別しやすくなります。
3. 手編集する場合は、移動後のフォルダにあるマテリアルを編集します。
4. 出力時は「ステップごとにエクスポート」のStep2で「手動で選択」にし、移動後の `Snapshot.asset` と、そのときのVRMを指定します。

**`Snapshot.asset` だけを移動しないでください。** マテリアルやテクスチャがGenerated内に残ると、次回の上書きで使えなくなることがあります。参照を保つため、移動はUnityのProjectウィンドウで行ってください。

「まとめてエクスポート」でマテリアル情報を残す設定がオフの場合は、保管用のSnapshotは残りません。手編集したい場合は、あらかじめオンにして出力してください。

新しいマテリアル情報の保存に失敗した場合は前回分が残ります。ただし、保存できた後にVRMや `.mouv` の出力で失敗した場合は、マテリアル情報の更新が済んでいることがあります。

## 詳細設定

| 設定 | 通常の使い方 |
| --- | --- |
| VRMをプロジェクトにも残す | 「まとめてエクスポート」専用です。通常はオフのまま使います。詳細設定内の「VRMの保存先」は、この項目をオンにすると入力でき、出力後もプロジェクト内のVRMを残します。空欄の場合は `Assets/MaterialOverrideVrm/` 以下に既存ファイルと重複しない名前で保存します。この場合も `.mouv` の拡張子を `.vrm` に変更したファイルを保存します。選択はEditorを起動し直すとオフに戻ります。 |
| エクスポートしたマテリアル情報をプロジェクトにも残す | 「まとめてエクスポート」専用です。通常はオフのまま使います。オンにすると `MaterialOverrideVrm/Generated` 以下へ保存します。手編集・保管したい場合に有効にしてください。この選択はEditorを起動し直すとオフに戻ります。 |
| エクスポート後もURPを維持 | 通常はオフのまま使います。出力のためにURPへ切り替えた場合、終了後に元の設定へ戻します。出力成功後もURPで作業したい場合だけオンにしてください。 |
| エクスポート用URP | **原則としてNoneのままで構いません。** 出力に必要なURPの設定は自動で用意します。特定のURP設定を使う必要がある場合に指定してください。 |

## 作業後の整理

出力した `.mouv` の保存先はUnityのConsoleにも表示します。「まとめてエクスポート」では `.vrm` の保存先も表示します。

特に **ステップごとにエクスポート** で作業を繰り返すと、ProjectウィンドウにVRMが増えていきます。不要になったVRMは、UnityのProjectウィンドウから適宜削除してください。後日再出力したい組み合わせのVRMや、ほかで使用しているものは残してください。

「まとめてエクスポート」でも、NDMF VRM Exporter自身が `Assets/NDMF VRM Exporter/` 以下に生成するVRMは残ります。こちらも不要になったものを適宜整理してください。

退避したマテリアル情報も、不要になったものはフォルダ単位で整理できます。生成済みの `.mouv` は、元のVRMやSnapshotをプロジェクトから削除した後も使用できますが、Unityで同じ状態から再出力するには元の組み合わせが必要です。

マテリアル保存を一度有効にすると、元アバターには **Capture Materials on VRM Export** コンポーネントが残ります。その後、NDMF VRM Exporterを別の画面から使った場合にもマテリアル情報を保存・上書きします。今後のVRM出力で保存したくない場合は、このコンポーネントの **Capture** をオフにするか、コンポーネントを無効化・削除してください。

## うまく出力・表示できないとき

- エクスポートボタンが押せない場合は、画面の警告とSetupの状態を確認してください。Step2では、出力済みVRMとマテリアル情報の両方が必要です。
- マテリアルの対応付けに失敗した場合は、VRMとSnapshotが同じ出力時の組み合わせか確認し、必要ならStep1からやり直してください。設定済みのモデルをシーンに残して修正する方式ではありません。
- VMagicMirrorで `.mouv` が正しく表示されない場合は、同じ出力時の `.vrm` を単独で読み込んで確認してください。VRMの変換設定・エラーは[NDMF VRM Exporterの説明](https://github.com/hkrn/ndmf-vrm-exporter)、`.mouv` の読み込み手順は[VMagicMirrorのTips](https://malaybaku.github.io/VMagicMirror/tips/use_material_override_vrm/)を参照できます。

不具合を報告する場合は、[GitHub Issues](https://github.com/malaybaku/MaterialOverrideVrmVRC/issues)へ、使用バージョン・エクスポート方法・エラーのConsoleログを添えてください。

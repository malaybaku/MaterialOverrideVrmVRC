# Material Override VRM for VRChat の使い方

このテキストでは本パッケージの利用方法を説明します。

## はじめに: このパッケージで作成するアバターファイル(.mouv)の特徴

本パッケージで出力する `.mouv` ファイルは以下のデータからなるファイルです。

- [NDMF VRM Exporter](https://github.com/hkrn/ndmf-vrm-exporter) によって変換したVRM相当のアバター情報
- マテリアル情報の一覧

出力の過程でVRMファイル (`.vrm`) も生成されます。

とくにマテリアル情報については、VRMへの変換直前にモデルに設定されていたマテリアルをURP向けに変換してファイルに格納します。ファイルのロード時にはこのマテリアルが適用され、VRM側に定義されたMToonマテリアルの情報は無視されます。

上記の特徴により、 `.mouv` ファイルでは以下の表現が可能です。

- VRMで指定できる揺れものやConstraint全般の反映
- MToonに限定しないマテリアルの適用

また、`.mouv` ファイルは下記の制約を受けます。

- URPをサポートしないシェーダーは使用できません。
- VRMのExpressionとして指定していない表情やBlendShapeを動かせることは保証されません。
- アニメーション等のデータは含まれません。

## インストール

- [baxter's VPM Packages](https://malaybaku.github.io/baku-vpm/) をVCC / ALCOMへ追加します。
- 本パッケージ (`Material Override VRM for VRChat`) を指定してインストールします。

## セットアップ

Editor上で **Tools > Material Override VRM > For VRChat: Setup** を選択し、案内に従ってパッケージを導入します。

パッケージのうち、とくにUniVRMはUPM (Unity Package Manager)での導入を想定しています。UniGLTF, およびVRM1.0パッケージにあたる下記2パッケージを **Window > Package Manager > + > Add package from git URL...** から追加します。

```
https://github.com/vrm-c/UniVRM.git?path=/Packages/UniGLTF#v0.131.4
https://github.com/vrm-c/UniVRM.git?path=/Packages/VRM10#v0.131.4
```

また、[NDMF VRM Exporter](https://github.com/hkrn/ndmf-vrm-exporter) が未導入の場合は別途VCC / ALCOMから導入します。


## エクスポート

Editor上で **Tools > Material Override VRM > For VRChat: Export** を開いてエクスポートを行います。

### 対象アバターのセットアップ

変換元となるアバターをシーン上に配置します。このアバターには `NDMF VRM Exporter` 用のエクスポート設定が指定されている必要があります。VRMへの変換設定の詳細は [NDMF VRM Exporter](https://github.com/hkrn/ndmf-vrm-exporter) の説明を参照してください。

なお、VRM Export Descriptionの設定のうち **MToon Options** はVRM(`.vrm`)の出力には影響しますが、最終的なエクスポート結果である `.mouv` での見え方には影響しません。

セットアップ後、下記いずれかの方法でエクスポートを行います。

- まとめてエクスポート: 推奨手順
- ステップごとにエクスポート: 推奨手順でうまくエクスポートできない場合の方法


### 推奨手順でのエクスポート: まとめてエクスポート

とくにアバターが `liltoon` のマテリアルのみを使用している場合、この方法でのエクスポートを推奨しています。

`エクスポート方法` を `まとめてエクスポート` に指定し、 `元アバター` に対象アバターを指定して `エクスポート` を実行します。この方法を使う場合、エクスポート中に生成したVRMファイルも別途 `.vrm` として保存されます。

詳細設定では下記のオプションが利用可能です。いずれもデフォルトでは変更不要です。

- `VRMをプロジェクトにも残す`: エクスポート中にプロジェクトの `Assets` 配下にインポートしたVRMを削除せずに残します。
  - VRMが意図通りに出力されているかをEditor上でチェックしたい場合はオンにします。
  - オンにした場合、保存先をあわせて指定します。
- `エクスポートしたマテリアル情報をプロジェクトにも残す`: `.mouv` ファイルに含めたマテリアル情報をプロジェクトの `Assets` 配下に `Assets/MaterialOverrideVrm/Generated/<アバター名>` というフォルダパスでも残します。
  - 出力した `.mouv` ファイルの表示に問題がある場合の調査時などにオンにします。
  - このオプションが必要な場合、エクスポート前にマテリアルを調整したい可能性があります。次のセクションも参照してください。
- `エクスポート後もURPを維持`: エクスポート後、プロジェクトのRender PipelineをURPに変更した状態を維持します。
  - URPでのマテリアル表示に問題がある場合の調査などで、必要に応じてオンにします。
  - このオプションを有効にした場合、後で `Project Settings > Graphics > Scriptable Render Pipeline Settings` を `None` にするとRender PipelineをBuilt-in RPに変更します。
- `エクスポート用URP`: この設定は高度なデバッグ目的で用意されているため、通常は未指定のままにしてください。


## 必要な場合：ステップごとにエクスポート

推奨手順でのエクスポートに問題がある場合、この方法でエクスポートを行います。この手順ではマテリアルを調整できるタイミングがあるため、URP対応で手作業が必要な場合に利用できます。

`エクスポート方法` を `ステップごとエクスポート` に指定し、後述の2つのステップに分けて `.vrm` ファイルと `.mouv` ファイルを出力します。

### Step1：VRM (.vrm) を出力

以下の手順でVRMファイルを出力します。

- `元アバター` に、対象となるアバターを指定します。
- その後、`マテリアル保存を有効にする` を実行し、`マテリアルの保存: セットアップ済み` という表示になることを確認します。
- `NDMF VRM ExporterでVRMを出力` にある `Export` を選択し、VRMを出力します。このVRMはStep2で参照するため、プロジェクトの `Assets` 以下のフォルダに保存します。

VRMの出力とあわせて、アバターのマテリアルおよびテクスチャの情報が `Assets/MaterialOverrideVrm/Generated/<アバター名>_<id>` のようなパスのフォルダ以下に出力されます。

この出力先は同名のアバターを繰り返し出力すると上書きされます。手でマテリアル情報を編集したい場合、後述の `マテリアル情報(Material Snapshot)を編集してからエクスポートする` のセクションを参照してください。

### Step2：Material Override VRM (.mouv) を出力

以下の手順で、VRMファイルにマテリアル情報を付与した `.mouv` ファイルを出力します。

- `出力済みVRM` に、Step1で出力したVRMを指定します。この指定時にはシーン上のモデルではなく、prefabを指定します。
- `マテリアルの指定方法` を適宜選択します。デフォルトでは `自動で選択 (VRMのアバター名と一致する最新)` を指定することで、Step1で生成されたマテリアル情報が紐付けられます。
- `エクスポート` を実行します。

`マテリアルの指定方法` について、バックアップして手で編集したマテリアル情報を指定したい場合は `手動で選択` に切り替えます。

詳細設定の項目はいずれも `まとめてエクスポート` で指定できるのと同様です。

- `エクスポート後もURPを維持`: エクスポート後、プロジェクトのRender PipelineをURPに変更した状態を維持します。
- `エクスポート用URP`: この設定は高度なデバッグ目的で用意されているため、通常は未指定のままにしてください。

### マテリアル情報(Material Snapshot)を編集してからエクスポートする

シェーダーがURP未対応の場合等では、Step1の実行後、Step2の実行前でマテリアルを編集しておくことで適切なエクスポート結果が得られます。

- `Project Settings > Graphics > Scriptable Render Pipeline Settings`でURP用のRender Pipelineを指定することでRender Pipelineを変更します。
  - *所定のURPアセットを半自動で指定できる手順を整備予定ですが、現行バージョンでは未サポートです。
- Step1でマテリアル情報が出力されたフォルダ (`Assets/MaterialOverrideVrm/Generated/<アバター名>_<id>`)を、フォルダごと別の場所に移動・リネームして退避します。
- フォルダに含まれるマテリアルのシェーダーやプロパティ等をURP向けに調整します。
- マテリアルの外観をInspector等で確認します。
  - *VRMをシーンに配置してマテリアルの差し替えをプレビューできる処理の整備を予定していますが、現行バージョンでは未サポートです。
- Step2で `マテリアルの指定方法` を `手動で選択` に変更し、退避したフォルダに含まれる `Snapshot.asset` を指定します。


## 不要なコンポーネントの削除について

`まとめてエクスポート` によるエクスポートを一度実行するか、または `ステップごとにエクスポート` のStep1を実行すると、出力元アバターに `Capture Materials on VRM Export` コンポーネントが残り、NDMF VRM Exporterの変換前にマテリアルのスナップショットを保存するようになります。この挙動を停止させるには、コンポーネントの `Capture` をオフにするか、コンポーネントを削除してください。
